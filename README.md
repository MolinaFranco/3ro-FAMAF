# 3ro-Famaf

Materiales del 3er año de la Licenciatura en Ciencias de la Computación (FAMAF, UNC).

## Estructura

```
3ro-Famaf/
├── lab-arquitectura/         # Arquitectura de Computadoras
│   ├── armv8/                # Assembly ARMv8
│   ├── DebugArch64/          # Ejercicios de debug/GDB
│   ├── adc-gem5/             # Proyecto con simulador GEM5
│   └── labmicroarqui/        # Labs de microarquitectura
│
├── lab-base-de-datos/        # Bases de Datos
│   ├── teoria/               # Apuntes y libros (Silberschatz, etc.)
│   ├── Practicos/            # Enunciados de prácticos
│   ├── Labs/                 # Labs adicionales
│   ├── LabsMysql/            # Prácticos MySQL (P2-P9, parciales)
│   ├── LabsMongo/            # Prácticos MongoDB
│   └── datasets/             # Datasets SQL (world-data, world-schema)
│
├── lab-discreta/             # Matemática Discreta II
│   └── labs-matematica-discreta-ii/  # Lab1, Lab2, práctica de grafos (C)
│
├── lab-ingenieria/           # Ingeniería de Software
│   ├── la-cosa-back/         # Backend (Python/FastAPI)
│   └── la-cosa-front/        # Frontend (Next.js)
│
├── lab-paradigmas/           # Paradigmas de Programación
│   ├── grupo12_lab01_2023/   # Lab 1 (Haskell)
│   ├── grupo12_lab02_2023/   # Lab 2 (Ruby)
│   └── grupo12_lab03_2023/   # Lab 3 (Java/Maven)
│
└── lab-redes/                # Redes y Sistemas Distribuidos
    ├── lab1_kickstart/       # Material inicial
    ├── redes23lab1g16/       # Lab 1 (grupo 16)
    ├── redes23lab2g16/       # Lab 2
    └── redes23lab3g16/       # Lab 3 (original/modificado/diseño)
```
